Assistant:
Do not pass the existing current_time. It counts only the thread's own sleep time; it does not increase while the thread is blocked at sem_wait(), so it cannot show the real difference between an attempt and successful operation.

Use one shared start time and calculate actual elapsed program time:

    time_t start_time;

    int elapsed_time() {
        return (int)(time(NULL) - start_time);
    }

Set it once in main before creating threads:

    srand(time(0));
    start_time = time(NULL);

Use elapsed_time() in the attempt messages, immediately before calling the buffer methods. Then print elapsed_time() inside insert_item and remove_item after sem_wait and pthread_mutex_lock have succeeded. Example completed-operation messages:

    printf("Producer produced %d at time %d\n", item, elapsed_time());
    printf("Consumer consumed %d at time %d\n", item, elapsed_time());

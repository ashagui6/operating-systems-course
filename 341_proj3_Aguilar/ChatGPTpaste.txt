1. Thread output is nondeterministic. Even with 315 hard-coded, the OS decides which producer/consumer runs first. You should not expect an identical line-by-line output.

3. current_time is local to each thread, not the program’s actual elapsed time. With multiple threads, each has its own separate timer.
4. This line in consumer() has an error:

random does not exist inside consumer, and there is only one %d anyway. Change it to:

random = myRand();
